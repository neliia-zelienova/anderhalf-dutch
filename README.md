# anderhalf-dutch
Not double dutch. Just anderhalf 🤏

This is Dutch vocabulary learning app, that will help you with daily vocabulary from the words you've added. Modules with 30+ words just doesn't work. Same as learning words that you will only use in the zoo (that schildpad from the green owl, you know). 

Select yourself or allow app to select for you! Practice and consistency makes in perfect. 1 day, 10 words, 5 minutes and after some time double Dutch becomes anderhalf
